# Анализатор пиков Dota 2

Сайт и API, которые подсказывают, какого героя лучше взять в драфт: по контрпикам против врагов,
синергии с союзниками и силе героя в мете. Драфт можно заполнить вручную или загрузить скриншот —
герои распознаются по верхней панели игры.

## Запуск локально

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload
```

Открой http://localhost:8000. При первом запуске сервер около минуты загружает статистику из OpenDota
и сохраняет её в `data/`; пока загрузка идёт, API отвечает `503`.

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MIN_RANK` | `75` | Минимальный средний ранг матча (`75` — Divine 5, `80` — Immortal) |
| `WINDOW_DAYS` | `8` | За сколько последних дней брать матчи |
| `REFRESH_HOURS` | `6` | Как часто догружать новые матчи |
| `OPENDOTA_API_KEY` | — | Ключ OpenDota, если упрётесь в бесплатные лимиты |
| `DATA_DIR` | `./data` | Куда сохранять матчи и портреты новых героев |
| `ANTHROPIC_API_KEY` | — | Нужен только для распознавания фото экрана через Claude. Без него работают скриншоты всего экрана |
| `CLAUDE_MODEL` | `claude-haiku-5-5` | Модель для фото экрана: Haiku стоит ~0,15 цента за фото; если ошибается — `claude-sonnet-5-5` (~2–3 цента) |
| `VISION_EFFORT` | `low` | Глубина размышлений модели (`low`, `medium`, `high`): выше — точнее и дороже |
| `CLAUDE_DAILY_LIMIT` | `200` | Максимум запросов к Claude в сутки на весь сервер |
| `CLAUDE_PER_IP_HOURLY` | `10` | Максимум запросов к Claude в час с одного IP |
| `ADMIN_TOKEN` | — | Токен для ручного обновления статистики; без него эндпоинт выключен |

## API

Интерактивная документация: `/docs`.

- `GET /api/health` — `{"ok": true, "ready": true, "error": null}`; `ready` становится `true`, когда статистика загружена.
- `GET /api/meta` — источник, `min_rank`, `window_days`, число матчей, время первого/последнего матча и обновления,
  `photo_recognition` (настроен ли Claude).
- `GET /api/heroes` — список героев: `id`, `name`, `npc`, `img`, `positions` (доля игр на позициях 1–5), `winrate`, `games`.
- `POST /api/analyze` — рекомендации для драфта:

  ```json
  {
    "ally": [{"id": 1, "pos": 1}, {"id": 5, "pos": 5}],
    "enemy": [{"id": 14, "pos": 4}],
    "bans": [74],
    "side": "ally",
    "pos": 0,
    "replace": null,
    "weights": {"counter": 1.0, "synergy": 0.7, "meta": 1.0},
    "limit": 15
  }
  ```

  `side` — для кого подбирать (`ally` или `enemy`), `pos` — позиция 1–5 (`0` — любая свободная).
  `replace: {"team": "ally", "index": 0}` — подобрать замену герою в этом слоте: подбор идёт на его позицию без него самого.

  Ответ: `recommendations` — герои по убыванию `score`, у каждого `id`, `name`, `pos`, `winrate`, `games`,
  `counter`, `synergy`, `meta`, `score` (в долях винрейта), `vs` и `with` — вклад каждого врага и союзника
  (`id`, `adv`, `games`), а в режиме замены ещё `delta` — разница с текущим героем.
  `current` — оценка заменяемого героя (или `null`), `advantage` — перевес драфта нашей команды (или `null`).
- `POST /api/recognize` — multipart-форма с полем `image` (PNG/JPEG/WebP до 15 МБ) и необязательным `allow_claude`
  (`true` по умолчанию). Ответ: `method` (`topbar` или `claude`), `radiant`, `dire`, `bans` — списки `id` героев.
  Если верхняя панель не найдена и Claude не настроен или запрещён, возвращается `422`.
- `POST /api/admin/refresh` — догрузить статистику прямо сейчас; заголовок `X-Admin-Token: <ADMIN_TOKEN>`.

## Откуда данные

- Матчи — таблица `public_matches` в [OpenDota Explorer](https://docs.opendota.com/): составы команд и победитель
  публичных матчей со средним рангом `avg_rank_tier >= 75` (рейтинговые All Pick и Captains Mode длительнее 15 минут) за последние 8 дней.
  Из них считаются винрейты героев, матчапы и синергии. Новые матчи догружаются каждые 6 часов.
- Позиции героев в публичных матчах не указаны, поэтому доли позиций взяты из снимка Dota 2 Pro Tracker
  (`app/resources/positions.json`). Новым героям, которых там нет, позиции прикидываются по их ролям.
- Портреты для распознавания лежат в `static/heroes/`; портреты новых героев сервер скачивает сам.

## Деплой на Render

1. Залей репозиторий на GitHub.
2. В Render: **New → Blueprint**, выбери репозиторий — сервис создастся из `render.yaml`.
3. Укажи `ANTHROPIC_API_KEY`, если нужно распознавание фото экрана. `ADMIN_TOKEN` Render сгенерирует сам.

Ограничения бесплатного плана: сервис засыпает после 15 минут без запросов, а диск временный. После
пробуждения первый запрос ждёт, пока сервер заново загрузит статистику (около минуты).
